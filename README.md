# TiketKita

A simple ticket-booking website inspired by online travel platforms, built as a data structures and algorithms project.

## Features

- **Ticket listing:** Display sample airline tickets and their prices.
- **Sorting:** Bubble Sort orders tickets from cheapest to most expensive.
- **Searching:** Linear Search finds tickets by destination.
- **Algorithm logs:** View the sorting and searching steps through a toggleable log panel.
- **Web interface:** Django backend with HTML, CSS, and JavaScript.
- **C++ integration:** Ticket sorting and searching are implemented in C++.

## Technologies

- Python and Django
- C++
- HTML, CSS, and JavaScript

## Project Structure

- `cpp/` — C++ algorithm implementation
- `web/` — Django application and frontend

## Running Locally

1. Install Python and a C++ compiler.
2. Set up the Python virtual environment and install Django.
3. Compile the C++ source code for your operating system.
4. Start the Django development server.
5. Open the local website in your browser.

**Note:** This is an educational demonstration. Ticket data is simulated, and actual reservations are not supported.
